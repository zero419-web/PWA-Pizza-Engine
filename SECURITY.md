# 🛡️ Security Policy 🛡️

## 🐞 Segnalazione <br> Bug Standard
Per bug comuni, errori di compilazione o refusi, puoi aprire tranquillamente una **Issue pubblica** sul repository.

## 🐞🚨 Errori Gravi <br> e <br> Vulnerabilità
Se trovi una **vulnerabilità grave**, una **falla di sicurezza o un bug critico** che potrebbe compromettere l'applicazione:

1. **Apri una Issue pubblica.**
2. indicando solo un **titolo generico** ( es. *"Rilevato potenziale problema critico"* ).
3. **NON inserire i dettagli tecnici** o i passaggi per replicare la falla **nella Issue pubblica.**
4. **Invia la spiegazione dettagliata** in modo **privato** e sicuro **tramite questo modulo dedicato:**

👉 [**Compila il Modulo di Segnalazione Sicura ( Google Forms )**](https://docs.google.com/forms/d/e/1FAIpQLSegCqkuqOCiwbYUuFGwNeDzxhhtFSMKb1gWGqMtwdwyRJ0lJw/viewform)

🙏 **Grazie per l'aiuto nel mantenere il progetto sicuro!** 🚀
